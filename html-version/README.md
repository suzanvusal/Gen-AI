## \ud83d\ude80 QUICK START (30 Seconds)

### Step 1: Download/Copy Files

You need these 10 files:
```
only-green/
├── index.html
├── shop.html
├── cart.html
├── about.html
├── contact.html
├── styles.css
├── products.js
├── cart.js
├── whatsapp.js
└── script.js
```

### Step 2: Setup WhatsApp Number

Open `whatsapp.js` and change this line:

```javascript
const WHATSAPP_NUMBER = '1234567890'; // Replace with YOUR number
```

**Examples:**
- US number `+1 555-123-4567` → Use: `15551234567`
- India number `+91 98765 43210` → Use: `919876543210`
- UK number `+44 7700 900123` → Use: `447700900123`

**Important:** No spaces, no dashes, no + sign!

### Step 3: Open in Browser

**Double-click** `index.html` or **right-click** → Open with → Your Browser

**Done! \u2705 Your website is running!**

## \u2699\ufe0f Customization

### Change Products

Edit `products.js`:

```javascript\nconst products = [\n    {\n        id: 1,\n        name: 'Your Product',\n        category: 'Category',\n        price: 29.99,\n        image: 'your-image-url',\n        description: 'Description'\n    }\n];\n```

### Change Colors

Edit `styles.css` (top of file):

```css\n:root {\n    --primary-green: #166534;  /* Change this */\n    --beige: #fef3c7;         /* Change this */\n}\n```

### Change Text

Edit any `.html` file - just edit the text between tags!

## \ud83d\udc1b Troubleshooting

### WhatsApp not opening?
- Check your number format in `whatsapp.js`
- Must include country code
- No spaces or special characters

### Products not showing?
- Check browser console (F12)
- Make sure all files are in same folder

### Cart not saving?
- Check if localStorage is enabled
- Try in different browser

### Images not loading?
- Check internet connection
- Images are loaded from external URLs
